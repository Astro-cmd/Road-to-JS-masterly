# JavaScript DOM Practice

A collection of small, standalone HTML, CSS, and JavaScript exercises for practicing DOM manipulation and browser events.

## Projects

| Project | Entry point | What it demonstrates |
| --- | --- | --- |
| Sports event delegation | [`index.html`](index.html) | Event delegation, dynamic list items, and click styling |
| Quote generator | [`quoteApp/index.html`](quoteApp/index.html) | Button events, arrays of objects, and random selection |
| FAQ accordion | [`FAQpage/index.html`](FAQpage/index.html) | Class toggling and accordion behavior |
| Modal | [`modal/index.html`](modal/index.html) | Opening, closing, and outside-click handling |

## Run locally

These are static browser projects and do not require a package manager or build step.

1. Clone or download the repository.
2. Open any project's `index.html` file in a browser.
3. For a smoother development workflow, open the repository in VS Code and use a static server extension such as Live Server.

Each project keeps its HTML, JavaScript, styles, and image assets together in its own directory.

## Repository structure

```text
.
├── index.html          # Sports event delegation demo
├── index.js
├── style.css
├── quoteApp/           # Random quote generator
├── FAQpage/            # FAQ accordion

```

## Learning goals

- Select and update DOM elements.
- Respond to user events.
- Use event delegation for dynamic content.
- Toggle CSS classes to control UI state.
- Keep small browser exercises easy to inspect and run.
